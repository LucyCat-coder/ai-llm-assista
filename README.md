# Проект анализа логов LLM-ассистента психологической поддержки

Этот проект — набор инструментов для анализа работы **робота-психолога** (LLM-ассистента). Он помогает понять:

- насколько быстро отвечает ассистент;
- нравятся ли его ответы людям;
- хорошо ли работает система безопасности (блокирует ли опасные сообщения);
- насколько можно доверять полученным цифрам.

Код написан на Python и использует базовую статистику, теорию вероятностей и метод бутстрэпа. Он создан специально для дипломной работы, но подойдёт и для любого похожего проекта.

---

## Что вы получите в итоге?

После запуска программы вы увидите в консоли:

- **среднее время ответа**, медиану, разброс;
- **среднюю оценку пользователя** и **доверительный интервал** (диапазон, в котором с высокой вероятностью находится истинная средняя оценка);
- таблицу, показывающую, как часто срабатывает система безопасности и насколько она точна;
- **байесовскую вероятность** опасности сообщения (обновлённую после срабатывания фильтра);
- график распределения бутстрэп-средних (наглядно показывает неопределённость оценки).

Все результаты также сохраняются в файл `results.txt`.
