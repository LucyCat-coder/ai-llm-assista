# Краткая инструкция для экзамена

## Структура
- `notebooks/` — учебные ноутбуки (solved и TODO)
- `src/` — минимальный код проекта
- `docs/` — краткая инструкция для экзамена
- `data/` — данные проекта
- `tests/` — место для тестов

## Что находится в папках

### notebooks
Здесь лежат ноутбуки по блока 4.  
Для каждого занятия есть:  
- solved – готовая версия  
- todo – версия для самостоятельной работы  

### src
Минимальный код проекта.  

### docs
Инструкции и пояснения.  

### data
Папка для данных. Сейчас почти пустая.  

### tests
Папка под тесты. В этом примере она оставлена как заготовка.
